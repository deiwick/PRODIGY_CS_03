# 🔐 Password Complexity Checker

## 📌 Overview
The **Password Complexity Checker** is a simple yet effective tool built to evaluate the strength of user passwords.  
It helps users understand whether their chosen password meets recommended security standards by analyzing length, character diversity, and overall complexity.

---

## ✨ Features
- Checks password length against minimum security requirements
- Validates presence of:
  - Uppercase letters
  - Lowercase letters
  - Numbers
  - Special characters
- Provides a **complexity score** (Weak, Moderate, Strong)
- Offers suggestions to improve weak passwords
- Lightweight and beginner-friendly implementation
